## Bootstrap

`frontend/src/main.tsx` wraps the app in:

1. `QueryClientProvider`
2. `BrowserRouter` with tenant basename
3. `ThemeProvider`
4. `AuthProvider`
5. `TenantThemeProvider`
6. `App`

`App.tsx` wraps `AppRoutes` in an `ErrorBoundary` reset by pathname and search string.

## Routing

`frontend/src/routes/AppRoutes.tsx` is the route registry. It uses lazy route imports so the first page no longer downloads the entire page surface. Route access is enforced by `RequireRoles`, which redirects unauthorized users to a role-appropriate home path.

Main route groups:

- Public: login, invite, password recovery, public archive.
- Superadmin: `/superadmin`.
- Club admin: dashboard, association, people, finance, memorial, settings.
- Sports director/admin: games, athletes, fields, clubs, competitions, rankings.
- Associate/athlete portals: `/associado`, `/minha-conta`.

## Auth State

`AuthProvider` in `frontend/src/context/AuthContext.tsx`:

- Stores token through `frontend/src/services/api.ts`.
- Stores active role in localStorage per workspace key.
- Loads `/auth/me` on startup when a token exists.
- Supports role switching for users with multiple roles.

## Tenant and Module Awareness

- `frontend/src/utils/tenantPath.ts` derives workspace and tenant path behavior.
- `apiRequest` sends `X-Tenant-Slug` for path-based tenant routing.
- `frontend/src/data/navigation.ts` maps paths to `TenantModuleCode`.
- `AppLayout` redirects away from routes whose module is disabled for the tenant.
- Tenant branding is fetched through `/tenant/current` and `/tenant/branding`.

## UI Organization

Reusable components are intentionally concentrated under `frontend/src/components`:

- `layout`: shell, sidebar, topbar, logo.
- `ui`: domain reusable elements such as pitch board, shirt renderer, Pix modal, date field.
- `ErrorBoundary`: route-level resilience.

Business pages live in `frontend/src/pages`, often grouped by domain rather than by route segment. Several files are large domain surfaces, especially `OperationsPages.tsx`, `ProductAreaPages.tsx`, `ArchivePages.tsx`, and `FinanceiroPage.tsx`.

## Performance Notes

The route table has been updated to lazy-load pages. After this change, the primary production JS chunk is about 102 KB minified, down from about 1.37 MB. Remaining large lazy chunks are domain-area chunks, especially operations and charts, and only load when the user enters those areas.
