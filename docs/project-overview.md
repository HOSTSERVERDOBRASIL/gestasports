# Sistema de Futebol Project Overview

Generated by BMAD document-project on 2026-06-24.

## Executive Summary

Sistema de Futebol, branded in the product as GestaSports, is a full-stack SaaS platform for sports club management. It supports a platform-level superadmin area and isolated club tenant workspaces with modules for associates, athletes, finance, games, statistics, events, gallery, archive, settings, and tenant billing.

The repository is a multi-part application:

| Part | Path | Type | Primary Stack |
| --- | --- | --- | --- |
| Backend API | `src`, `prisma`, `scripts` | Backend service | TypeScript, Fastify, Prisma, PostgreSQL, Zod, JWT |
| Frontend app | `frontend` | Web app | React, TypeScript, Vite, React Router, React Query, Recharts, Tailwind |

## Architecture Classification

The system is a full-stack TypeScript SaaS monorepo-style repository with two deployable parts:

- A Fastify API that serves `/api/*` and `/health`, applies tenant context, authorization, module gating, and Prisma tenant scoping.
- A React SPA built by Vite and served from `frontend/dist` by the backend in production.

The central architectural constraint is tenant isolation. Tenant context is resolved from host, subdomain, custom domain, or `X-Tenant-Slug`, then propagated through Fastify request lifecycle and Prisma query extensions.

## Key Capabilities

- Platform control plane: tenants, plans, SaaS billing, domains, enabled modules, provisioning.
- Club operations: associates, board roles, athletes, teams, fields, competitions, games, lineups, events, statistics.
- Finance: monthly fees, Pix checkout, collection dashboard, expenses, financial entries, reports.
- Archive and memorial: public and authenticated archive items, categories, documents, uniforms, awards, historical games.
- Role-based UX: superadmin, admin, financial, sports director, associate, athlete.
