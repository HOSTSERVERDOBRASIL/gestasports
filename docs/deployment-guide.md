# Deployment Guide

Generated by BMAD document-project on 2026-06-24.

## Build Artifacts

The production container builds both parts:

- Backend TypeScript output: `dist`
- Frontend static assets: `frontend/dist`
- Prisma schema and generated client

## Docker Build

```bash
docker compose -f docker-compose.prod.yml build
```

## Migration

Before starting the production app against a managed PostgreSQL database:

```bash
docker compose -f docker-compose.prod.yml run --rm app npx prisma migrate deploy
```

## Start

```bash
docker compose -f docker-compose.prod.yml up -d
```

The container exposes port `3333`.

## Required Production Environment

Use `.env.production` based on `.env.production.example`.

Required or important values:

- `NODE_ENV=production`
- `DATABASE_URL`
- `JWT_SECRET`
- `SAAS_APP_HOST`
- `CORS_ORIGINS` for custom domains outside the main app host
- SMTP settings for password recovery
- Optional Sicoob Pix settings and certificate paths

## Health Check

`docker-compose.prod.yml` checks:

```text
http://127.0.0.1:3333/health
```

## Production Notes

- CORS allows the app host, `www` app host, subdomains of the app host, and configured custom origins.
- The backend serves the frontend SPA when `frontend/dist/index.html` exists.
- Use `npm run check` before deployment to validate backend build, frontend build, lint, and Prisma schema.
