# Backend API Contracts

Generated by BMAD document-project on 2026-06-24.

## API Surface

All application endpoints are served under `/api` except `/health`. Route handlers are implemented in `src/modules/*/*.routes.ts`. Authentication is handled by Fastify decorators from `auth.plugin.ts`.

## Common Behaviors

- JSON is the primary request and response format.
- Zod validation errors return HTTP 400 with an `issues` array.
- Unauthorized requests return HTTP 401.
- Role failures return HTTP 403.
- Suspended or canceled tenant access can return HTTP 402 with code `TENANT_ACCESS_BLOCKED`.
- Disabled tenant modules can return HTTP 403 with code `TENANT_MODULE_DISABLED`.

## Frontend Client Contract

`frontend/src/services/api.ts` expects:

- JSON responses for most successful API requests.
- Empty 204 or `content-length: 0` responses to map to `undefined`.
- Error payloads to expose a string `message` when available.
- Downloads to return Blob responses through `apiDownload`.

## Contract Maintenance Guidance

- Keep new endpoints under `/api` unless intentionally public like `/health`.
- Define auth requirements at route registration with `app.authenticate` or `app.authorize`.
- Add matching frontend API calls through `apiRequest` so timeout, auth token, and tenant slug behavior stay consistent.
- Update this document when adding a new route module or significant endpoint group.
