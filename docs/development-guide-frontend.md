# Frontend Development Guide

Generated by BMAD document-project on 2026-06-24.

## Prerequisites

- Node.js 20+.
- npm.
- Backend API running on the same host during integrated development, or Vite proxy/configuration if added later.

## Install

```bash
npm --prefix frontend install
```

## Run Frontend

```bash
npm run frontend:dev
```

Default frontend URL:

- `http://localhost:5173`

## Build and Lint

```bash
npm run frontend:build
npm run frontend:lint
```

## Frontend Patterns

- Use `apiRequest` from `frontend/src/services/api.ts` for API calls.
- Use `AuthProvider` and `useAuth` for auth state.
- Add routes in `frontend/src/routes/AppRoutes.tsx`.
- Add navigation entries and module mapping in `frontend/src/data/navigation.ts`.
- Prefer route-level lazy loading for new pages.
- Keep domain page code near `frontend/src/pages`, reusable UI under `frontend/src/components`.

## Frontend Change Checklist

- Add role restrictions with `RequireRoles`.
- Add navigation only for the roles and modules that should see the feature.
- Keep backend module gating aligned with frontend module mapping.
- Run `npm run frontend:build` and `npm run frontend:lint`.
