- API client: `frontend/src/services/api.ts`

## Integration Points

- Frontend calls backend through relative `/api` paths.
- Auth token is stored per workspace key in localStorage.
- Tenant slug is derived from the current path and sent as `X-Tenant-Slug` when applicable.
- Backend can also resolve tenants from host, custom domain, and default subdomain.
- Production backend serves the compiled SPA from `frontend/dist`.
