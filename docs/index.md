## Project Overview

- **Project:** Sistema de Futebol / GestaSports
- **Type:** Multi-part full-stack SaaS application
- **Primary Language:** TypeScript
- **Architecture:** Fastify API plus React SPA with tenant-aware SaaS control plane
- **Primary Data Store:** PostgreSQL through Prisma

## Quick Reference

### Backend API (`backend`)

- **Root:** `.`
- **Type:** Backend service
- **Stack:** TypeScript, Fastify, Prisma, PostgreSQL, Zod, JWT
- **Entry Point:** `src/server.ts`
- **Architecture Pattern:** Modular route plugins with tenant-aware middleware and Prisma query extension

### Frontend SPA (`frontend`)

- **Root:** `frontend`
- **Type:** Web app
- **Stack:** React, TypeScript, Vite, React Router, React Query, Recharts, Tailwind
- **Entry Point:** `frontend/src/main.tsx`
- **Architecture Pattern:** Route-based SPA with lazy-loaded domain pages and provider-based state

## Getting Started

Install and run locally:

```bash
npm install
npm --prefix frontend install
docker-compose up -d postgres
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
```

Run backend and frontend in separate terminals:

```bash
npm run dev
npm run frontend:dev
```

Validate before merging or deploying:

```bash
npm run check
```
