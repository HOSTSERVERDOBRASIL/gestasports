# Backend Development Guide

Generated by BMAD document-project on 2026-06-24.

## Prerequisites

- Node.js 20+ for local development. Docker uses Node.js 22.
- npm.
- PostgreSQL, usually through `docker-compose.yml`.

## Install

```bash
npm install
npm --prefix frontend install
```

## Environment

Create `.env` from `.env.example`. Required local setting:

- `DATABASE_URL`

Production additionally requires a strong `JWT_SECRET` and SMTP settings for password recovery.

## Database

```bash
docker-compose up -d postgres
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
```

## Run API

```bash
npm run dev
```

Default API URL:

- `http://localhost:3333`
- Health: `http://localhost:3333/health`

## Validate

```bash
npm run build
npm run test
npm run prisma:validate
```

Full repository check:

```bash
npm run check
```

## Backend Change Checklist

- Add or update Zod schemas close to route handlers.
- Use `app.authenticate` or `app.authorize` for protected routes.
- Keep tenant-owned data behind Prisma tenant scoping.
- Add Prisma migrations for schema changes.
- Update frontend `moduleForPath` and backend module gating together when adding tenant modules.
