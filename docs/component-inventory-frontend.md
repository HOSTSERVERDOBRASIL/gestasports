## Page-Level Domains

Large page modules are grouped by domain:

- `OperationsPages.tsx`: associates, audit, settings, goalkeepers, games.
- `ProductAreaPages.tsx`: product-area screens such as events, fields, board, stats-related entries.
- `ArchivePages.tsx`: public archive and memorial sections.
- `FinanceiroPage.tsx`: club finance dashboard and operations.
- `SuperadminPage.tsx`: SaaS control plane.
- `RoleDashboardPages.tsx`: role-specific landing dashboards.

## Improvement Opportunities

- Split very large page files into smaller feature components when adding new behavior.
- Keep reusable form/table/status primitives in `components/ui` instead of duplicating them inside page files.
- Keep route-level lazy loading in place for new pages.
