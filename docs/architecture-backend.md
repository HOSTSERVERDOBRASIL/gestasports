## Runtime Flow

1. `src/server.ts` creates the Fastify app with a 6 MB body limit.
2. CORS is permissive in development and host-restricted in production.
3. The tenant plugin runs before auth and resolves the current tenant.
4. Auth and audit plugins decorate Fastify.
5. Route modules are registered, mostly with `/api` prefix.
6. If `frontend/dist` exists, it is served as static SPA content.
7. Unknown non-API GET requests fall back to `frontend/dist/index.html`.

## Tenant Architecture

Tenant resolution happens in `src/modules/tenancy/tenant.plugin.ts`:

- Reads `X-Forwarded-Host` or `Host`.
- Accepts `X-Tenant-Slug` for local/platform host fallback.
- Resolves verified custom domains through `TenantDomain`.
- Resolves default subdomains and tenant slugs.
- Stores tenant context with `AsyncLocalStorage` through `tenantContext`.

Prisma tenant enforcement happens in `src/lib/prisma.ts`:

- Applies `tenantId` to reads, updates, deletes, creates, createMany, and upserts for tenant-scoped models.
- Allows superadmin bypass through tenant context.
- Relies on tenant-scoped model lists from `src/modules/tenancy/tenant-context.ts`.

## Auth and Authorization

`src/modules/auth/auth.plugin.ts` registers JWT and provides:

- `app.authenticate` for logged-in access.
- `app.authorize(roles)` for role-based access.
- Superadmin tenant bypass.
- Sports director access to selected admin-oriented sports paths.
- Tenant status blocking for suspended or canceled tenants.
- Tenant module gating based on URL path and enabled `TenantModuleCode` values.

Primary roles:

- `SUPERADMIN`
- `ADMIN`
- `SPORTS_DIRECTOR`
- `FINANCIAL`
- `ASSOCIATE`
- `ATHLETE`

## Error Handling

- Zod errors return HTTP 400 with `issues`.
- Oversized body returns HTTP 413 with a user-facing upload size message.
- Unknown API routes return HTTP 404.
- Unexpected errors are logged and return HTTP 500.

## Architectural Constraints

- Add new tenant-owned models to the tenant-scoped model registry or they can bypass isolation.
- Keep superadmin routes explicit and protected by `SUPERADMIN`.
- Keep module gating aligned with frontend `moduleForPath` in `frontend/src/data/navigation.ts`.
- API routes should continue to use Zod schemas close to route handlers.
