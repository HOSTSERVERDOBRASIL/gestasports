## Tenant Isolation

Many operational models are tenant-owned and should include `tenantId`. Runtime isolation is enforced by the Prisma extension in `src/lib/prisma.ts`, which injects `tenantId` into supported operations when a tenant context exists.

When adding a new tenant-owned model:

1. Add `tenantId` and relation to `OrganizationTenant` in `schema.prisma`.
2. Add indexes/unique constraints that include `tenantId` where appropriate.
3. Add the model to the tenant-scoped model registry.
4. Add migration and seed/backfill logic if needed.
5. Validate with `npm run prisma:validate`.

## Migration Strategy

The repository uses Prisma migrations. Production deployment should use:

```bash
npm run prisma:generate
npm run prisma:migrate:deploy
```

Development migration command:

```bash
npm run prisma:migrate
```
